# Fin Malc video

Drop the video for the Fin Malc page into this folder.

1. Open this `videos` folder in GitHub.
2. Choose **Add file → Upload files**.
3. Upload your video and name it exactly `finlay.mp4`.
4. Commit the upload to `main`.

The website is already set to play `videos/finlay.mp4`. Keep the file in MP4 format. Once Cloudflare Pages redeploys, the video will appear on the Fin Malc page.
